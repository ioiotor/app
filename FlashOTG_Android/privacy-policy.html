本隐私政策（以下简称"本政策"）旨在向您说明 FlashOTG（以下简称"本软件"或"我们"）如何收集、使用和保护您的个人信息。

我们深知个人信息对您的重要性，并将以高度审慎的态度对待您的个人信息。请您仔细阅读并充分理解本政策。

重要提示：本软件是一款离线工具型应用，支持 ESP32/ESP8266 系列芯片与 Arduboy/AVR 设备的本地 USB 刷写，并支持将您主动选择的手机本地视频/图片转换为 128×64 单色帧、在已连接的 Arduboy 设备屏幕上播放。本软件不联网、不上传您的任何信息，不读取或收集您的剪切板信息；仅在您的设备本地存储偏好设置、法律条款同意状态、简洁模式镜像副本与运行日志。

一、我们不收集的信息

本软件是一款纯本地运行的固件烧录工具。我们不收集、不上传您的以下任何信息：

1.1 个人身份信息（PII）：包括但不限于您的姓名、电话号码、电子邮件地址、身份证件号码、生物识别信息等。

1.2 设备标识信息：包括但不限于您的手机 IMEI、MEID、序列号、MAC 地址、Android ID / OAID 等设备唯一标识符。

1.3 位置信息：本软件不会获取您的精确或大致地理位置。

1.4 使用数据：本软件不会收集您的使用习惯、点击行为、操作频率等分析数据。

1.5 固件内容：您所读取、烧录或导出的任何固件文件（.hex / .bin / .arduboy / BIN）及其内容始终仅存在于您的本地设备上，本软件不会读取、复制、上传或共享这些文件的内容。

1.6 设备信息：您所连接的 Arduboy/AVR 或 ESP 设备的芯片 ID、MAC 地址等硬件标识信息仅用于当前连接会话的本地设备识别；部分硬件标识可能出现在运行日志中用于故障排查，但不会被单独存储或上传至任何服务器。您可通过卸载本软件清除全部本地数据。

1.7 视频与图片文件：您在"设备屏幕播放"或"图像转换"中主动选择的本地视频/图片文件仅在本机进行解码与格式转换，转换后的帧数据仅通过 USB 发送至您已连接的设备；本软件不会读取、复制、上传或共享这些文件的内容。按您指定位置导出的帧序列文件仅保存在您的本地设备上。

1.8 剪切板信息：本软件不会读取、写入或收集您的剪切板（剪贴板）信息。应用内的"分享日志/分享链接"功能通过 Android 系统分享面板（ACTION_SEND）由您选择目标应用处理，本软件不访问剪贴板，也不会上传剪切板内容。

二、权限使用说明

2.1 为正常提供服务，本软件可能需要申请以下系统权限，但其使用严格限制于特定功能场景：

  • a) USB 设备访问权限
    • 用途：与 Arduboy/AVR 或 ESP 设备建立串口通信，执行识别、烧录、备份、校验、设备状态显示或设备屏幕播放等操作
    • 数据流向：仅在您的手机与目标设备之间建立本地有线连接
    • 不会以任何方式通过网络传输通信内容
  • b) 文件访问（系统文件选择器 Storage Access Framework）
    • 用途：通过系统文件选择器让您选择固件文件（.hex / .bin / .arduboy）、待播放的视频/图片文件，或将备份/导出文件、帧序列文件保存到您指定的位置
    • 仅在您主动点击"选择文件"、"选择视频文件"、"导出"或"备份"时触发
    • 视频/图片文件仅在本机解码与转换，不会上传；本软件不会主动扫描您的存储空间，文件保存位置由您自行指定

2.2 您授予的所有权限仅用于上述功能，不会被用于任何其他目的。您可以随时在系统设置中撤销已授予的权限。

三、数据存储

3.1 本软件在您的设备上可能存储以下本地数据：

  • a) 您手动选择的语言、主题、应用模式等偏好设置及法律条款同意状态；
  • b) 简洁模式下的镜像副本（仅用于一键刷入，保存在应用私有目录，可在应用内清除或随卸载删除）；
  • c) 运行日志（仅保存于设备本地存储，用于故障排查）。

3.2 上述数据完全存储于您的设备本地，不会上传至任何远程服务器。您可以随时通过"清空日志"功能删除运行日志，也可以卸载本软件以清除所有本地数据。
